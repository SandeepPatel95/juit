Syllabus

This is a 3-1-0 (L–T–P)

  • Unit 1: Overview of Linear Data Structures
    Overview of linear data structures: array, linked list, stack, and queue.
  • Unit 2: Searching, Sorting, and Hashing
    Searching and sorting algorithms Interpolation Search, Median Search; Hashing Hash Table, Chaining, Probing; Sorting Merge, Quick, Radix, Bucket, and Count; Time and Space complexity analysis of searching and sorting algorithms.
  • Unit 3: Advanced Trees and Heaps
    Implementation of Multi List, Binary Tree, K-ary Tree, Tree traversals, Threaded Binary Tree, Priority Queue using Binary Heap, Binomial Heap, and Fibonacci Heap, Heap Sort.
  • Unit 4: Search Trees and Multiway Trees
    Binary Search Tree (BST), Balanced BST: AVL Tree and RB Tree; Multiway Tree: B Tree and B+ Tree.
  • Unit 5: Graph Fundamentals and Algorithms
    Fundamentals of Graph, Adjacency Matrix and List; Graph Traversal using DFS and BFS, Basic Algorithms Shortest Path and Minimum Spanning Tree.
  • Unit 6: Special Trees and String Data Structures
    Interval Tree, Segment Tree, and String Data Structures: Suffix Tree, Tries, Suffix Array.
